# 用户的固定情况（默认值）

> 这是 europe-route-finder 的个人设置。换成你自己的情况：出发城市、持有的车票和折扣卡、住宿偏好、不能接受的交通方式、换乘上限。agent 每次查路线前都会先读这个文件。

- 住在莱比锡，默认从莱比锡出发。
- 持有 **Deutschlandticket**：德国境内的区域车（RE / RB / S-Bahn / 城市公交）免费；不含 ICE / IC / EC，也不含其他国家的区域车。
- 持有 **BahnCard 25**：在 bahn.de 查价时要选上 BahnCard 25（2. Klasse），Flexpreis 和 Sparpreis 都打 75 折。比价平台通常不认 BahnCard，所以 DB 官网往往更便宜，这点要在对比里体现。DB 联程票里的境外段是否也享受折扣，以 bahn.de 实际显示的价格为准。
- **不坐过夜大巴，无论多便宜。** 用户宁愿白天累一点，也不能让晚上的睡眠受影响。夜间运行的大巴（包括「下午出发、第二天凌晨到」的大巴）一律不列入方案，也不放进「排除的方案」里推销。大巴只考虑白天的班次。
- 中途过夜偏好**青旅**，只住一晚、第二天就走。房型优先级：**女生间 → 没有女生间再看混合多人间**。
- 用户是 **Booking 最高等级的 Genius 会员**，她登录后看到的 Booking 价格通常比未登录时低（例如伯尔尼女生间公开价约 39€，她看到 33€）。
- **换乘次数按段算，不按全程算。** 两个大城市（枢纽）之间的一段，换乘不超过 3 次就可以接受，例如莱比锡 → 布鲁塞尔、莱比锡 → 日内瓦、莱比锡 → 伯尔尼各自 ≤3 次。从枢纽到小镇的最后一段（区域火车、大巴、缆车、站间巴士）本来就要换几次，不计入这个限制。一段超过 3 次换乘的才排除。
